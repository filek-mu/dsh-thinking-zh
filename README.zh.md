# dsh-thinking-zh

在 DSH 对话中阅读中文的模型思考内容。

[English](README.md)

## 安装

本插件是 DSH bundle，只通过 GitHub 仓库分发，不发布到 npm：

1. 克隆仓库：

   ```bash
   git clone https://github.com/filek-mu/dsh-thinking-zh.git
   ```

2. 在 DSH 的「插件」页点「添加插件」，选择克隆下来的目录；或者用 `plugin_manager` 的 `install_bundle` 传入该目录的绝对路径。
3. 启用「思考中文翻译」，保持它的两个子项同时启用，刷新页面后展开任意思考内容。

在 DSH `0.2.2-rc.5` 上验证。插件挂载的是 DSH 自带的实验性翻译包，升级 DSH 后行为可能变化。

> 注意：npm 上另有一个同名的 `dsh-thinking-zh`（作者 minutiae3），与本项目无关。请从本仓库以本地目录方式安装，不要执行 `npm install dsh-thinking-zh`。

## 功能

本插件挂载 DSH 自带的思考翻译模块，并把默认值固定为简体中文：

- 翻译服务：Bing 匿名翻译接口。
- 目标语言：`zh`（简体中文）。
- 翻译范围：展开的思考行正文。
- 原文保留：Session 记录、模型上下文、折叠摘要都保持原文。

## 使用方法

1. 在对话中展开一段思考内容，已完成的段落会自动换成简体中文；首批译文返回前，正文仍显示原文。
2. 思考正文上方的工具栏可在 **查看原文** 和 **查看译文** 之间切换。流式段落尚未写完的末尾会保持原文，写完后再翻译。
3. **查看原文** 只切换显示，不会取消已经发出的翻译请求；要停止请求请收起思考行或停用插件。
4. 翻译失败时正文保持原文，并提供 **重试**；不会自动切换到别的服务。

插件页里的两个子项（翻译服务、思考翻译）需要同时保持启用；也不要同时启用官方的「思考过程机器翻译」，两者使用同一组插件行。

已完成的段落会陆续翻译。收起思考行或停用插件会取消未完成的请求。成功的译文会保存在 Session 中，重新展开、刷新页面或重启 Host 后复用。

## 隐私与网络

当前展开的思考正文会经 DSH Host 发送到微软的 Bing 匿名翻译接口，其中可能包含私有代码或对话细节。这里不使用 Google，Bing 是唯一配置的服务。Bing 等匿名接口不保证可用性与免费额度；中国大陆的连通性取决于你的网络。翻译服务不会收到任何登录凭据。

## 已知限制

- 只翻译展开的正文；折叠时的思考摘要保留原文语言。
- 首批译文返回前，“查看原文/查看译文”切换可能看不到变化。
- 机器翻译可能改变 Markdown 格式或代码示例；原文始终可以一键切回。
- 未激活且没有已保存译文的子代理 Session，其思考内容可能保持原文。
- 本插件封装 DSH 自带的实验性翻译包，DSH 升级可能改变其行为。

## 停用

在插件页面停用「思考中文翻译」。思考工具栏会消失、待处理请求会被取消；已保存的译文仍保留在 Session 日志中。
